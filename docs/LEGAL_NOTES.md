# CET Tracker — 合规边界说明

## 项目性质

CET Tracker 是一个**个人备考追踪工具**，不是内容分发平台。其核心功能是记录用户自己的训练过程、错题复盘和词汇笔记。

## 合规边界

### 本项目不提供以下内容

| 类别 | 说明 |
|------|------|
| CET 真题试题 | 不内置、不分发任何 CET-4/CET-6 真题题目、题干、选项 |
| CET 听力音频 | 不提供、不内置任何 CET 听力音频文件 |
| CET 阅读文章 | 不提供、不内置任何 CET 阅读理解的原文 |
| 官方答案与评分标准 | 不提供 CET 官方答案、评分细则或分数换算表 |
| 第三方教辅内容 | 不提供任何出版社的教辅解析、技巧总结或范文 |
| 出版物扫描件 | 不内置任何书籍、试卷的扫描页或电子版 |

### 用户自行负责的内容

- 用户可自行输入错题编号、错误类型标签和反思笔记
- 用户可通过 Markdown 导入功能构建个人词汇笔记
- 用户可自行导入个人训练数据

**用户应确保自行导入或记录的材料来源合法。**

### 演示数据

`scripts/seed_demo.py` 中的所有数据均为**虚构演示数据**：
- 训练记录使用虚构的试卷名称和日期
- 词汇条目为通用英语词汇，不来自任何特定 CET 真题
- 演示数据仅供开发测试使用

### 开源与再分发

- 本项目代码以 MIT 许可证开源
- 开源的是追踪工具本身，不包含任何 CET 考试内容
- 第三方 fork、修改或再分发本项目时，应同样确保不包含受版权保护的考试材料

### 风险提示

如果本项目的任何演示数据、文档示例或默认文案被认定为不恰当，请通过 GitHub Issues 报告，我们将及时修正。
