# CET Tracker v0.3.3 — GitHub 开源首发

**发布日期**：2026-05-19

## 版本摘要

v0.3.3 是 CET Tracker 首次公开发布版本。在 v0.3.2-fix 全部测试通过的基础上，完成了 GitHub 开源前的展示、文档、打包和发布准备工作。

## 核心功能

该版本包含以下完整功能模块：

- **训练记录** — 模考/听力/阅读训练结果记录，错题号 + 错因标签
- **听力精听** — 状态追踪（未开始 / 进行中 / 已完成）
- **阅读错因统计** — 按题型、按标签的错误分布分析
- **词汇笔记本** — Markdown 导入 + 输入单词列表 AI 生成结构化笔记
- **词汇复习** — 卡片式间隔复习，again/hard/good/easy 四档评分
- **间隔重复** — 自动计算下次复习时间
- **复盘任务** — 从训练结果自动生成专项复盘任务
- **周报/月报** — 规则化训练总结，一键复制
- **仪表盘** — 统计卡片 + ECharts 图表
- **数据管理** — JSON 完整导入/导出

## 已知限制

1. **AI 功能为可选** — 不配置 DeepSeek API Key 时，词汇生成功能不可用，Markdown 导入完全可用
2. **仅限单用户本地使用** — 无多用户、无云同步、无远程访问
3. **无真题内容** — 本项目不提供任何 CET 真题，用户需自行记录训练数据
4. **E2E 测试未配置** — Playwright 测试未搭建，路由验证由 API smoke 覆盖
5. **截图待补充** — README 中的页面截图将在后续版本中添加

## 安全与版权

- **数据隐私**：所有数据存储在本地 SQLite 数据库，无遥测、无追踪
- **API Key 安全**：AI 功能的 API Key 仅存在于后端 `.env`，不进入前端构建产物或 git 仓库
- **版权合规**：本项目不提供、不内置、不分发任何 CET 真题内容
- **演示数据**：`scripts/reset_demo_data.py` 使用虚构数据
